# MouseNudge v1.0.0

Initial Windows release.

- Periodically move the mouse in a configured direction.
- Optionally return the pointer to its starting position.
- Alternatively press a configured keyboard key; `F15` is the default.
- Configure the action and interval in `appsettings.json`.
- Includes a self-contained `win-x64` executable; no .NET installation is required.

Download `MouseNudge-v1.0.0-win-x64.zip`, extract it, edit `appsettings.json` if needed, and run `MouseNudge.exe`.
